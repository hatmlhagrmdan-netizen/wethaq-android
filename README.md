# وَثاق

النسخة النهائية قيد التحقق الآلي من تطبيق وَثاق للتواصل.

- هوية المستخدم: الاسم الثلاثي + سنة الميلاد
- معرف وَثاق تلقائي
- تسجيل ودخول وحفظ الهوية
- البحث العام عن المستخدمين وإضافة جهات الاتصال
- محادثات ورسائل عبر REST وWebSocket
- حفظ الرسائل محليًا عند انقطاع الشبكة وإعادة إرسالها عند عودتها
- واجهة عربية RTL ومهيأة للهاتف
- خادم مستقل داخل `backend/`
- صلاحيات إدارة محمية من الخادم
- حظر مؤقت ونهائي وإلغاء الحظر
- نظام شكاوى للإدارة
- إصدار Android: `1.8.0`

يتم بناء Release APK آليًا والتحقق من سلامة APK قبل نشر Artifact النهائي.

تم تثبيت مسار الإصدار النهائي مع إصلاحات الواجهة والوسائط قبل البناء.
