# وَثاق

النسخة النظيفة من تطبيق وَثاق للتواصل.

- هوية المستخدم: الاسم الثلاثي + سنة الميلاد فقط
- معرف تلقائي مثل `Hatem_Hussin_Al_Haj_Ramadan1995`
- لا توجد كلمة مرور
- صورة الهوية الرسمية محفوظة في `app/src/main/res/drawable/profile_photo.jpg`
- تسجيل/دخول وحفظ الهوية
- البحث عن المستخدمين وإضافة جهات الاتصال
- محادثات ورسائل عبر REST وWebSocket
- واجهة عربية RTL ومهيأة للهاتف
- خادم مستقل داخل `backend/`

هذه الشجرة تحتوي على ملفات التشغيل الضرورية فقط، ولا تعتمد على ملفات ZIP أو لقطات شاشة أو أدوات إصلاح قديمة.
