# وَثاق

النسخة الحالية قيد التحقق الآلي من تطبيق وَثاق للتواصل.

- هوية المستخدم: الاسم الثلاثي + سنة الميلاد
- معرف وَثاق تلقائي
- تسجيل ودخول وحفظ الهوية
- البحث العام عن المستخدمين وإضافة جهات الاتصال
- محادثات ورسائل عبر REST وWebSocket
- حفظ الرسائل محليًا عند انقطاع الشبكة وإعادة إرسالها عند عودتها
- واجهة عربية RTL ومهيأة للهاتف
- خادم مستقل داخل `backend/`
- صلاحيات إدارة محمية من الخادم
- حظر مؤقت ونهائي وإلغاء الحظر
- نظام شكاوى للإدارة
- إصدار Android: `2.4.0` (`versionCode 8`)

مسار CI يبني نسخة تحقق منفصلة موقعة بمفتاح الاختبار فقط، حتى يمكن البناء والفحص دون ملفات أسرار الإنتاج.
أما `release` فلا يُعد إصدارًا إنتاجيًا إلا عند توفير متغيرات توقيع الإنتاج (`WETHAQ_KEYSTORE_PATH` و`WETHAQ_KEYSTORE_PASSWORD` و`WETHAQ_KEY_ALIAS` و`WETHAQ_KEY_PASSWORD`) واستخدام مفتاح الإنتاج الصحيح.

يتضمن التحقق الآلي الآن تدقيقًا بنيويًا، واختبارًا فعليًا لربط `better-sqlite3` الأصلي، واختبار Smoke لمسارات الهوية والبحث وجهة الاتصال والرسائل، ثم بناء APK وفحص سلامة التوقيع والملف.
