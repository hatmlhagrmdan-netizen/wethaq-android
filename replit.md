# Replit Source-of-Truth

Wethaq Android development must use this GitHub repository as the canonical source of truth:

- Repository: `https://github.com/hatmlhagrmdan-netizen/wethaq-android.git`
- Branch: `main`
- Application: Wethaq — وَثاق Android

Do not use, import, sync, or publish changes from the unrelated `Country Leader` / `رئيس الدولة` project for Wethaq.

All Wethaq Android source changes, configuration changes, documentation, CI changes, and release-related changes must be made against this repository. Preserve the existing Android application and its current messaging, calls, notifications, security, identity, and backend behavior unless a requested change explicitly targets one of them.

Replit is a development workspace only; GitHub remains the canonical repository and review history.
