# وَثاق — قسم الإدارة والهرمية الإدارية النهائية

هذه الوثيقة هي المواصفة المرجعية لقسم الإدارة في وَثاق. القسم العام إعلامي للمستخدمين، بينما لوحة التحكم الإدارية محمية بمصادقة مستقلة تعتمد على بيانات المستخدم والرمز السري للمنصب.

## 1) قسم الإدارة العام

يرى المستخدمون في **👥 الإدارة** الرتب، الرسوم السنوية، العدد المسموح، الصلاحيات العامة، ونسماء المعينين فعليًا. عند تعيين شخص جديد يظهر اسمه تحت الرتبة الصحيحة، مع بيان **تم التعيين بواسطة** ووقت التعيين. إذا كان المقعد فارغًا يظهر **شاغر**.

لا تظهر في القسم العام الرموز السرية أو كلمات المرور أو مفاتيح الجلسات أو أي بيانات اعتماد.

## 2) عند تعيين مستخدم

بعد نجاح التعيين في الخادم:

1. تُحفظ الرتبة وحالة التعيين.
2. يُحفظ صاحب التعيين ورتبته ووقت التعيين.
3. يُولد **رمز سري فريد لهذا التعيين**.
4. يُحفظ الرمز في الخادم بصيغة آمنة غير قابلة للاستخدام ككلمة مرور مكشوفة.
5. تصل إلى المستخدم رسالة/بطاقة تهنئة إدارية عبر نظام رسائل وَثاق.
6. تظهر البطاقة فيها الرتبة الجديدة، الرمز السري، وبيان التواصل مع مدير ومؤسس وَثاق لبدء المهمة واستلام الصلاحيات.
7. يظهر اسم المستخدم مباشرة ضمن قسم الإدارة.

### نموذج بطاقة التهنئة

**🎉 بطاقة تهنئة من وَثاق**

تهانينا [اسم المستخدم]!

تم تعيينك رسميًا في منصب:
**[رمز المنصب] [اسم المنصب]**

🔐 **رمز المنصب السري:** [رمز خاص بالمستخدم]

للبدء في مهمتك واستلام الصلاحيات، يرجى التواصل مع **مدير ومؤسس وَثاق** لبدء مهمتك واستلام الصلاحيات.

**تم التعيين بواسطة:** [اسم المعين] — [رتبته]

> الرمز سري ومخصص لهذا الحساب وهذا المنصب فقط، ولا يجوز مشاركته مع أي شخص.

## 3) الدخول إلى لوحة التحكم الإدارية

المستخدم المعين لا يستخدم الرمز الشخصي المعتاد للوصول إلى لوحة منصبه. يوجد مسار إداري منفصل:

**الاسم الثلاثي + سنة الميلاد + الرمز السري للمنصب**.

بعد نجاح التحقق:

- يتم إنهاء جلسة الحساب الشخصي من الجهاز وفق هذا المسار.
- يحصل المستخدم على جلسة إدارية مستقلة.
- تفتح **لوحة التحكم الخاصة بمنصبه**.
- تعرض اللوحة فقط الصلاحيات الفعلية الممنوحة للرتبة.
- لا يمكن للرمز فتح رتبة أعلى أو منح صلاحيات إضافية.
- انتهاء التعيين أو انتهاء الاشتراك أو إلغاؤه يسقط الجلسة الإدارية عند إعادة التحقق.

## 6) قواعد التعيين

- المؤسس: إدارة الهيكل بالكامل.
- المدير التنفيذي: أعضاء الإدارة + أعضاء مميزون.
- النائب الأول: 3 أعضاء إدارة + أعضاء مميزون.
- النائب الثاني: أعضاء الإدارة + أعضاء مميزون.
- النائب الثالث: أعضاء مميزون فقط.
- المشرف: أعضاء مميزون فقط ضمن الحد المضبوط.
- عضو الإدارة وعضو مميز: لا تعيين.
- لا يجوز تجاوز سعة أي رتبة.
- لا يجوز تعيين رتبة أعلى من صلاحية المنفذ.

## 7) الحظر والتنبيه

- المؤسس محمي من الحظر والإزالة.
- لا يجوز لأي رتبة تجاوز نطاق الحظر المخصص لها.
- الحظر المؤقت يحمل مدة وسببًا.
- كل حظر أو إلغاء حظر أو تحذير أو تعيين أو إزالة تعيين يسجل في Audit Log.

## 8) الاشتراك والصلاحية

- الرسوم سنوية.
- انتهاء الاشتراك يسقط الصلاحيات الإدارية.
- الـBackend هو مصدر الحقيقة للحالة والصلاحيات، وليس النص المحلي داخل Android.
- الرمز السري خاص بكل تعيين، وليس رمزًا عامًا مشتركًا.

## 9) النتيجة النهائية المطلوبة

**تعيين → ظهور اسم المستخدم في قسم الإدارة → بطاقة تهنئة ورسالة بالمنصب → رمز سري خاص بالتعيين → تسجيل الخروج من الحساب الشخصي عند تفعيل المسار الإداري → إدخال الاسم الثلاثي + الميلاد + الرمز السري → فتح لوحة الصلاحيات الخاصة بالمنصب.**
